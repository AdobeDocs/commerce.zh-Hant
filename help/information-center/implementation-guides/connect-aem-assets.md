# 將Adobe Commerce連線至AEM Assets以進行資產管理

AEM Assets可根據Adobe Commerce產品，透過不同的整合路徑連線至Commerce。

針對雲端基礎結構上的Adobe Commerce，請使用適用於Commerce的AEM Assets整合。 若為Adobe Commerce as a Cloud Service和Adobe Commerce Optimizer，請使用AEM Assets所支援的產品視覺效果。

>[!NOTE]
>
>本指南涵蓋Adobe Commerce在雲端基礎結構、Adobe Commerce as a Cloud Service和Adobe Commerce Optimizer上的AEM Assets整合路徑。 請遵循符合您的產品和部署的路徑。

## 快速入門

1. 檢閱Commerce的[AEM Assets整合](/help/aem-assets-integration/overview.md)檔案，瞭解必要條件和設定。


1. 若要使用AEM Assets啟用資產管理，請在&#x200B;_[適用於Commerce的AEM Assets整合指南](/help/aem-assets-integration/overview.md)_&#x200B;中針對您的部署型別遵循[後續步驟](/help/aem-assets-integration/overview.md#next-steps)指示。
