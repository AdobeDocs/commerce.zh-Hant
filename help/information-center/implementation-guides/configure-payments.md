# 設定付款

[!DNL Payment Services]為購物者提供多種付款方式，包括免息分期付款，並為商家提供統一的控制面板，以管理付款、訂單和發票。

>[!NOTE]
>
>本指南適用於Adobe Commerce （雲端或內部部署）、Adobe Commerce as a Cloud Service或Magento Open Source處理交易時。 對於Adobe Commerce Optimizer專案，只有在交易式後端是這些支援的平台之一時，才會遵循此流程。 若是協力廠商後端處理交易，請改用該後端付款設定。

## 快速入門

1. 檢查[付款服務相容性](https://experienceleague.adobe.com/en/docs/commerce/payment-services/compatibility)中的產品版本與國家/地區可用性。

1. 遵循[上線支付服務流程](/help/payment-services/onboard.md)。

1. 如果您的Commerce雲端或內部部署執行個體未連線至Commerce Services，請先依照[設定Commerce服務](set-up-commerce-services.md)操作。
