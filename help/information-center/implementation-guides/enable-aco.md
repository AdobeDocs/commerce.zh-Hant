# 啟用Adobe Commerce Optimizer

[!DNL Adobe Commerce Optimizer]是可撰寫的銷售和產品探索層，可透過[!DNL Adobe Commerce Optimizer Connector]連線至Adobe Commerce雲端或內部部署，並支援Edge Delivery Services上建立的店面。 Adobe Commerce as a Cloud Service目前不提供此功能。

## 快速入門

1. 檢閱[什麼是Adobe Commerce Optimizer？](/help/optimizer/overview.md) 以瞭解其所提供的功能。

1. 如需Adobe Commerce Optimizer中的設定步驟，請參閱[開始使用](/help/optimizer/get-started.md)。

1. 對於雲端或內部部署的Commerce，請依照[[!DNL Adobe Commerce Optimizer Connector]](/help/aco-connector/overview.md)檔案指示，匯出目錄資料、同步價格，並連線您的店面。
