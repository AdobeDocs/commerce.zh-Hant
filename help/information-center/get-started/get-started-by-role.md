# 角色快速入門

Adobe Commerce檔案可跨多個存放庫和網站組織。 正確的起點取決於您的角色，以及管理員和銷售人員適用之專案使用的平台和銷售路徑。 如果您不確定哪一個平台適用於您，請參閱[平台和服務](../portfolio/platform-and-services.md)。

## 適用於商務從業人員

瞭解什麼是Adobe Commerce以及管理員和店面如何共同運作。

- [[!DNL Adobe Commerce as a Cloud Service] 概覽](/help/cloud-service/overview.md)

- [[!DNL Adobe Commerce Optimizer role-based workflows]](/help/optimizer/get-started.md#role-based-workflows)

- [Adobe Commerce快速入門手冊](https://experienceleague.adobe.com/en/docs/commerce-admin/start/guide-overview)


## 適用於銷售商

Adobe Commerce有兩個銷售路徑。 適用且可供您使用的專案取決於您的後端，而非您的角色：

- **[!DNL Live Search]、[!DNL Product Recommendations]和[!DNL Catalog Service]擴充功能** — 搭配[!DNL Adobe Commerce as a Cloud Service]和Adobe Commerce （雲端或內部部署）使用。 請參閱下列指南：

- [什麼是Live Search？](/help/live-search/overview.md)
- [什麼是產品建議？](/help/product-recommendations/overview.md)
- 適用於Adobe Commerce](/help/catalog-service/overview.md)的[目錄服務。

- **在[!DNL Adobe Commerce Optimizer]**&#x200B;中的原生銷售 — 當Adobe Commerce on Cloud或內部部署使用[!DNL Adobe Commerce Optimizer Connector]連線至[!DNL Adobe Commerce Optimizer]時使用。 請參閱[銷售概述](/help/optimizer/merchandising/overview.md)。

## 適用於管理員

安裝程式會依平台以及您的專案是否使用[!DNL Adobe Commerce Optimizer]而有所不同：

- **[!DNL Adobe Commerce as a Cloud Service]** — 已自動安裝及設定Commerce服務。 請參閱[Adobe Commerce as a Cloud Service快速入門](/help/cloud-service/getting-started.md)。

- **[!DNL Adobe Commerce Optimizer]** — 您獨立於Commerce後端所設定的軟體即服務(SaaS)產品。 請參閱[開始使用Adobe Commerce Optimizer](/help/optimizer/get-started.md)。

- **[!DNL Adobe Commerce Optimizer Connector]和[!DNL Adobe Commerce Optimizer Connector for B2B]** — 將Adobe Commerce （雲端或內部部署）連線至Adobe Commerce Optimizer。 請參閱[開始使用Adobe Commerce Optimizer聯結器](/help/aco-connector/get-started.md)。

- **雲端或內部部署(PaaS)上的Adobe Commerce** — 在設定之前，請先安裝每個Commerce服務擴充功能。 如需詳細指示，請參閱每個擴充功能的指南。

- [開始使用即時搜尋](/help/live-search/install.md)
- [安裝及設定產品推薦](/help/product-recommendations/install-configure.md)
- [目錄服務安裝](/help/catalog-service/installation.md)。

- 如需雲端或內部部署Adobe Commerce的平台管理，請參閱：

- [雲端基礎結構上的Commerce指南](https://experienceleague.adobe.com/en/docs/commerce-on-cloud/user-guide/overview)
- 內部部署的[Adobe Commerce作業指南](https://experienceleague.adobe.com/en/docs/commerce-operations/operational-guides/home)。
