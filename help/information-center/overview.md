# 關於Commerce資訊中心

Commerce資訊中心是Adobe Commerce檔案生態系統的跨產品進入點。 使用它在Adobe Commerce、[!DNL Adobe Commerce Optimizer]、[!DNL Adobe Commerce as a Cloud Service]和相關Commerce服務中尋找正確的產品、實作指引和架構建議，而不需搜尋多個檔案網站。

各產品的權威性深入檔案會繼續出現在自己的指南中。 資訊中心負責該內容的策展和連結，讓您能夠在一個地方開始工作，並更快到達正確的目的地。

## 快速入門

| 章節 | 使用它可以 |
| ------- | --------- |
| [由角色開始](get-started/get-started-by-role.md) | 根據您的角色尋找起點 — 業務從業人員、銷售人員、管理員、開發人員、解決方案架構者或合作夥伴。 |
| [平台和服務](portfolio/platform-and-services.md) | 瞭解Adobe Commerce產品組合，並識別哪些產品和服務符合您的需求。 |
| [選擇Commerce選項](portfolio/choose-commerce-option.md) | 根據您的部署偏好設定、營運需求以及想要的基礎架構管理層級，取得選擇正確Commerce產品的相關指引。 |
| [店面](storefronts/overview.md) | 瞭解Adobe Commerce中可用的不同店面選項。 |
| Commerce的[AEM Assets整合](aem-assets/aem-assets-integration.md) | 在任何Commerce或Optimizer架構中新增集中式數位資產管理。 |
| [API](apis/commerce-apis.md) | 探索Commerce Foundation、Storefront Services和Commerce Optimizer所使用的API系列。 |
| [實作指南](implementation-guides/overview.md) | 遵循常見實作歷程的跨產品指引，例如建立店面或連線Commerce服務。 |
| [架構選項](architecture-options/overview.md) | 比較支援的Commerce架構，並檢閱橫跨多個Commerce產品的參考模式。 |
| [深入分析和指引](guidance-and-insights/overview.md) | 尋找可用的策略指引，包括白皮書、安全性建議和最佳實務。 |
| [移轉與採用](migration-adoption/overview.md) | 規劃在架構之間移動，或分階段採用Adobe Commerce Optimizer。 |

>[!NOTE]
>
>Commerce資訊中心不會取代產品檔案。 如需逐步組態設定和參考資料，請遵循每一節中的連結，以取得權威產品指南。
