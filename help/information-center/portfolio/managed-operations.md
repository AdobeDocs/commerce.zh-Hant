# 具有受管理作業的[!DNL Adobe Commerce as a Cloud Service]

**啟動速度更快，執行更有信心。**

[!DNL Adobe Commerce as a Cloud Service]是完全受管理、無版本化的SaaS平台。 Adobe會託管、縮放、保護及更新核心應用程式和基礎架構，讓您的團隊可專注於打造絕佳的購物體驗。

具有Managed Operations **的**&#x200B;[!DNL Adobe Commerce as a Cloud Service]&#x200B;是進階產品，可搭配平台與專屬的Adobe Managed Services團隊和具名的客戶成功工程師(CSE)。 他們一起監視、引導和最佳化您的完整商務解決方案，包括您的[!DNL App Builder]應用程式、整合和由[!DNL Edge Delivery Services]支援的[!DNL Commerce Storefront]，從上線到啟動和持續運作。

## 客戶成功工程師

您指定的CSE是您在Adobe的單一連絡視窗，也是完整[!DNL Adobe Commerce as a Cloud Service]工具集的專家，包括[!DNL Edge Delivery Services]支援的[!DNL App Builder]、[!DNL API Mesh]和[!DNL Commerce Storefront]。 您的CSE可與您和實作合作夥伴合作，以：

- 引導並支援您完成上線流程
- 管理布建和平台設定
- 提供整合和自訂的架構原則建議，包括[!DNL App Builder]應用程式和[!DNL Commerce Storefront] （由[!DNL Edge Delivery Services]提供技術支援）
- 支援[!DNL Adobe Commerce as a Cloud Service]更新程式
- 透過規劃、執行和監控提供事件支援
- 透過里程碑核對清單和專用的上線戰場，協調您的上線工作
- 建立和維護設定專用的Runbook
- 執行定期健康狀況和最佳化評估，並提出建議

>[!NOTE]
>
>您的CSE會提供指引和諮詢服務。 您（或您的實作合作夥伴）仍需負責開發及維護您的自訂專案。 請參閱[共用職責安全性與運作模型](/help/cloud-service/security/shared-responsibility.md)。

## 主動式監控和事件回應

Managed Services團隊會全天候監控您的完整解決方案（不僅限於平台），因此您可在問題影響購物者之前解決問題：

- **效能監視** — 持續追蹤頁面載入時間、回應時間和可用性。
- **流量監視** — 分析流量模式以偵測可能表示問題、威脅或容量需求的尖峰或異常行為。
- **自動警示** — 針對效能降低、停機或安全性事件發出警示，並由CSE主動提供外展服務。
- **增強的回應** — 更快的首次回應和解決時間，在優先事件期間會定期更新，並對符合資格的事件進行根本原因分析。

## 安全性

[!DNL Adobe Commerce as a Cloud Service]保護平台、基礎結構和核心應用程式的安全。 使用Managed Operations，您也可以：

- **主動式安全性指引** — 專家指引，確保您程式外自訂的安全性與合規性。
- **Web應用程式防火牆(WAF)調整與報告** — 規則會調整至標準全域規則集以外的流量，並定期報告封鎖的內容。
- **進階速率限制** — 提供額外的保護，避免體積攻擊。
- **安全性稽核與風險評估** — 定期審查漏洞，並計畫減少漏洞。
- **事件回應** — 針對安全性事件的即時行動計畫，以將影響與停機時間減至最低。
