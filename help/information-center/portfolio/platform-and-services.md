# 探索Adobe Commerce平台和服務

無論您是需要完整的Commerce平台、選擇如何託管和操作，還是希望店面和目錄功能與現有的Commerce後端相結合，Adobe Commerce都能提供符合您需求的選項。 在人類主導和代理的購物歷程中，Adobe Commerce可協助品牌透過AI支援的產品探索、快如閃電的店面和按一下即可結帳，提高轉換率和平均訂單價值。 本概述將比較核心方案，並介紹可擴充這些方案的服務與開發人員工具，協助您找出起點，並驗證哪些功能適合您的實施。

每種服務提供的服務都不同。 規劃實作時，請檢閱檔案以取得特定產品和部署模型。

## Commerce方案

### B2C和B2B商務

Adobe Commerce支援B2C和B2B商業模式，包括單一Commerce執行個體上的這兩種模式。 [Adobe Commerce B2B簡介](https://experienceleague.adobe.com/en/docs/commerce-admin/b2b/introduction)

B2B功能依產品而異。 對於雲端基礎結構上的Adobe Commerce和內部部署，Adobe Commerce B2B是需要個別授權和安裝的擴充功能。 Adobe Commerce as a Cloud Service包含核心B2B功能，例如預設的公司管理和報價。 請參閱[Adobe Commerce B2B](https://experienceleague.adobe.com/en/docs/commerce-admin/start/resources/extensions)。

### Adobe Commerce as a Cloud Service

Adobe Commerce as a Cloud Service是完全受管理的雲端原生軟體即服務(SaaS)產品。 Adobe可管理核心Commerce應用程式、基礎架構和更新。 其元件包括Commerce基礎、由Edge Delivery Services支援的Commerce店面、銷售服務、產品視覺效果和開發人員工具。

請參閱[Adobe Commerce as a Cloud Service概觀](https://experienceleague.adobe.com/en/docs/commerce/cloud-service/overview)。

### Adobe Commerce Optimizer

Adobe Commerce Optimizer是一種SaaS解決方案，可改善店面、目錄、產品探索和銷售體驗。 它可與現有的Adobe Commerce或協力廠商商務後端搭配使用，讓組織在不取代管理交易系統的情況下，實現客戶體驗的現代化。

Adobe Commerce Optimizer可從第三方來源擷取目錄資料。 購物車和結帳與協力廠商系統的整合使用API Mesh和App Builder等整合工具。

請參閱[什麼是Adobe Commerce Optimizer？](https://experienceleague.adobe.com/en/docs/commerce/optimizer/overview)。

>[!NOTE]
>
>Adobe Commerce as a Cloud Service和Adobe Commerce Optimizer目前不會相互整合。 在規劃實作時，請將它們視為個別的架構選項。

### Adobe Commerce內部部署

Adobe Commerce內部部署是由商家或其託管提供者所託管。 商家或提供者會管理託管環境、基礎架構和平台服務。

請參閱[內部部署安裝概述](https://experienceleague.adobe.com/en/docs/commerce-operations/installation-guide/overview)。

### 雲端基礎結構上的Adobe Commerce

雲端基礎結構上的Adobe Commerce是平台即服務(PaaS)部署。 Adobe會管理託管平台，而商家則保留應用程式層級的維護、自訂程式碼、設定和其他共用責任工作的責任。

請參閱雲端基礎結構上的[Commerce](https://experienceleague.adobe.com/en/docs/commerce-on-cloud/user-guide/overview)和[移轉至Adobe Commerce as a Cloud Service](https://experienceleague.adobe.com/en/docs/commerce/cloud-service/migration/overview)。

## 延伸Commerce的服務

### 店面與商品銷售服務

適用於店面和產品體驗的Adobe Commerce服務包括：

- **[由Edge Delivery Services提供支援的Commerce店面](https://experienceleague.adobe.com/en/tools/commerce-storefront/merchants/quick-start/create-content/)** — 建置面向客戶的商務體驗的店面選項。
- **[Storefront Services](/help/landing/home.md)** — 適用於Adobe Commerce （包括[!DNL Adobe Commerce on cloud infrastructure]和[!DNL Adobe Commerce as a Cloud Service]）的雲端傳送SaaS功能，可支援店面API和服務，以進行最佳化的目錄存取、AI導向的搜尋和產品建議，以及付款處理，協助商戶改善購物體驗、效能和轉換
  - 目錄服務 — 支援最佳化的產品目錄體驗和店面效能。
  - 即時搜尋 — 提供AI支援的產品搜尋。
  - 產品建議 — 根據購物者行為、趨勢和產品相似度提供建議。
- **[Commerce Optimizer銷售服務](/help/optimizer/overview.md)** — 適用於Commerce on Cloud和Adobe Commerce as a Cloud Service的雲端傳送API優先功能，使用目錄資料和AI來改善產品探索，透過最佳化的目錄存取、相關的搜尋結果和個人化產品推薦來協助購物者尋找產品，並支援更好的店面效能和轉換。
  - **產品視覺效果** — 透過Adobe Experience Manager Assets整合支援產品影像和媒體。

### 付款

**付款服務**&#x200B;提供付款方式與付款處理、訂單及發票的檢視。 可用性取決於Commerce產品和部署。

請參閱[付款服務](https://experienceleague.adobe.com/en/docs/commerce/payment-services/guide-overview)。

### 資料與整合服務

Commerce包括用於連線平台和同步資料的服務和工具：

- **[Commerce服務聯結器](/help/landing/saas.md)** — 將雲端、內部部署或Magento Open Source上的Adobe Commerce連線到支援的Commerce SaaS服務。
- **[SaaS Data Export](/help/data-export/overview.md)** — 支援連線服務的Commerce資料移動和同步處理。
- **[資料連線](/help/data-connection/overview.md)** — 將Commerce資料連線至Adobe Experience Platform。
- **[Adobe Commerce Optimizer Connector](/help/aco-connector/overview.md)** — 將目錄和定價資料從支援的Adobe Commerce部署同步至Adobe Commerce Optimizer。
- **[平台特定聯結器](/help/optimizer/integrations/integrations-overview.md#commerce-salesforce-connector)** — 在支援的情況下，將Adobe Commerce Optimizer與特定的協力廠商商務平台連線。

### 開發人員工具和擴充功能

開發人員功能包括&#x200B;**Adobe Developer App Builder**、**API Mesh**、**活動**、**Webhooks**&#x200B;和&#x200B;**管理UI SDK**。 這些工具支援自訂應用程式、整合和擴充功能。 可用性因Commerce產品而異。

請參閱[Adobe Commerce開發人員檔案](https://developer.adobe.com/commerce/docs/)。
